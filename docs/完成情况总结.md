## SFML 配置

项目使用 SFML 3，通过 MSYS2 pacman 安装：
```bash
pacman -S mingw-w64-ucrt-x86_64-sfml
```

CMake 自动查找 SFML，无需手动指定路径。

## 构建方式

```bash
mkdir build && cd build
cmake .. -G "MinGW Makefiles"
mingw32-make
```
